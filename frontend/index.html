About CONTINUUM

College research project on intelligent cross-OS program continuity, GCC compilation orchestration, and transparent VM failover.

Mission & Architecture

CONTINUUM coordinates seamless cross-OS program continuity between a Windows host central controller and Linux execution nodes. When a developer submits C source code, CONTINUUM compiles and runs it on a primary VM (Kali Linux). If an execution failure is caused by an operating system environment deficiency (missing dependencies, uninstalled libraries, or agent downtime), CONTINUUM automatically and seamlessly migrates the source code, compiler flags, and input data to a backup VM (Parrot OS) without requiring manual developer intervention.

Rule-Based Failure Classifier Logic

An explainable rule-based failure classification engine distinguishes normal user mistakes from genuine OS environment defects:

Failure Category Typical Causes Controller Action Failover Triggered?
Category A (Normal Error) Syntax errors, missing semicolons, type mismatches, arithmetic overflow, logic errors. Returns compilation/runtime diagnostics directly. Halts cleanly. NO (No wasteful migration)
Category B (Environment Defect) Missing system headers, missing libraries, agent unreachable, toolchain configuration error. Probes Parrot OS health, automatically migrates source code, restarts execution. YES (Transparent Failover)
Watchdog Expiration Infinite loops, blocking stdin waits, execution exceeding timeout limit. Forcibly terminates process via SIGKILL. Returns timeout diagnostic. NO (Halts infinite compute)
